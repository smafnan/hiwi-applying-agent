USER JOURNEY
================================================================================

Step 1: WELCOME (30 sec)
  - See what HiWi Applying Agent does
  - Understand the 3 steps
  - Click "Get Started"

Step 2: PROFILE (2-3 min)
  - Enter name, email, degree
  - List top 4 skills
  - Describe 2 strongest projects
  - One key achievement
  - Optional work experience

Step 3: UPLOAD (1-2 min)
  - Upload BTU transcript (required)
  - Upload resume (optional)
  - Upload cover letter (optional)
  - Drag-and-drop interface

Step 4: REVIEW (1 min)
  - Confirm profile info
  - Verify files uploaded
  - Edit if needed
  - Submit

Step 5: RESULTS (45 min)
  - Watch real-time progress
  - See stats: professors found, emails drafted
  - Download Excel file
  - Get next steps

OUTCOME:
- Excel file with 15-30 personalized emails
- Ranked by fit score (0-100)
- Ready to send
- Day 7 + Day 18 follow-ups included

1. Professor Directory
   Why: Users want to see who they're emailing
   Benefit: Builds confidence, shows research areas

2. Skills Matcher
   Why: Visual learners need to see overlap
   Benefit: Justifies why email is relevant

3. Grant Visualizer
   Why: Funded professors more likely to hire
   Benefit: Prioritize high-probability targets

4. Tracking Dashboard
   Why: Users need to monitor progress
   Benefit: Stay organized across 20+ applications

   Why: Data-driven insights
   Benefit: Learn what works, optimize future outreach

6. Tone Selector
   Why: Different professors want different vibes

7. Mobile Responsive

DEPLOYMENT OPTIONS
================================================================================

Development:
```
docker-compose up
# or
python main.py (backend) + npm run dev (frontend)
```

Production (Heroku):
```
heroku create hiwi-applying-agent
git push heroku main
heroku open
```

Production (AWS):
```
# ECR + ECS
aws ecr create-repository --repository-name hiwi-applying-agent
docker build -t hiwi-applying-agent:latest .
# Push to ECR and deploy
```

Production (DigitalOcean):
```
# App Platform
doctl apps create --spec app.yaml
```
